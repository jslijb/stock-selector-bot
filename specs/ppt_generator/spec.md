# PPT 生成功能规格说明书

## 1. 功能概述

为选股系统新增 PPT 自动生成能力。用户提供文字内容（如选股报告、因子分析、市场总结），系统自动：
- 解析文本结构，拆分为幻灯片
- 自动判断是否需要插入图片/图表
- 调用 LLM 提炼文字要点
- 生成 `.pptx` 文件

---

## 2. 需求列表

| 编号 | 需求 | 优先级 |
|------|------|--------|
| R1 | 输入纯文本，输出 PPT | P0 |
| R2 | 输入文本 + 图片路径，输出带图片的 PPT | P0 |
| R3 | 仅输入文本时，系统自动判断是否需要生成图表（数据型内容） | P0 |
| R4 | 支持 Markdown 格式输入 | P1 |
| R5 | 从选股结果直接生成 PPT（如 `-p2` 完成后可选输出 PPT） | P1 |
| R6 | 幻灯片模板可配置（字体/颜色/布局） | P2 |
| R7 | CLI 命令集成（`python main.py -ppt`） | P0 |

## 4. 模块设计

### 4.1 目录结构

```
src/ppt/
├── __init__.py
├── generator.py        # PPT 生成主控（python-pptx）
├── content_parser.py   # 文本解析（Markdown → 结构化）
├── image_decider.py    # 图片需求自动判断
├── chart_renderer.py   # matplotlib 图表渲染
└── templates.py        # 幻灯片模板（字体/颜色/布局）
```

### 4.2 核心类与方法

#### ContentParser
```
输入: raw_text: str
输出: List[SlideContent]
  SlideContent:
    - title: str          # 幻灯片标题
    - bullet_points: List[str]  # 要点列表
    - has_data: bool      # 是否含数据
    - image_paths: List[str]    # 用户指定的图片路径
    - chart_data: Optional[dict] # 如需自动生成图表，包含数据
```

#### ContentSummarizer
```
输入: paragraphs: List[Paragraph]
输出: List[SlideContent]  # 提炼后的幻灯片内容

- 调用 LLM（复用 reasoning/engine.py 的 LLM 客户端）
- Prompt: "将以下内容整理为PPT幻灯片结构，每页不超过5个要点"
- 如果无 LLM → 本地规则分页（按标题/H2 分割）
```

#### ImageDecider
```
输入: slide_content: SlideContent
输出: SlideContent  # 补充了 chart_data 字段

决策规则（优先级从高到低）：
1. 用户提供了 image_paths → 直接使用，不生成
2. 内容含 ≥3 个数值 + 百分比 → 标记需生成图表
3. 选股报告特定字段(持仓/权重) → 生成饼图/柱状图
4. 其他 → 纯文字
```

#### PptGenerator
```
输入: slides: List[SlideContent], title: str
输出: .pptx 文件路径

幻灯片尺寸: 16:9 (13.33" × 7.5")
颜色方案: 深蓝标题 + 白色背景
字体: 微软雅黑 (中文), Calibri (英文)
```

## 6. 图片自动判断逻辑

```python
def should_generate_chart(text: str) -> bool:
    """
    判断是否需要为这段文字生成图表：
    1. 提取数字（含百分号、亿、万等单位）
    2. 如果有 ≥3 个数值 → 建议生成图表
    3. 特殊场景：选股报告 → 无条件生成
    """
    import re
    numbers = re.findall(r'\d+\.?\d*(?:%|亿|万|倍)?', text)
    return len(numbers) >= 3
```

## 7. CLI 集成

```bash
# 从文本文件生成 PPT（自动判断图片）
python main.py -ppt report.txt

# 从 Markdown 文件生成
python main.py -ppt analysis.md

# 指定图片目录（图片文件名需与 Markdown 章节对应）
python main.py -ppt report.md --img-dir ./charts/

# 从选股结果直接生成（-p2 完成后自动调用）
python main.py -p2 20240101 20260506 --ppt

# 纯文本命令行输入
python main.py -ppt - --title "月度选股报告" --text "今日选出XXX"
```

## 11. 验收标准

- [ ] 输入纯文本 → 输出至少 3 页 PPT
- [ ] 输入 Markdown（含 ## 标题） → 按标题分页
- [ ] 输入含 ≥3 个数值的段落 → 自动生成柱状图/折线图
- [ ] 输入 `--img-dir` → 图片插入对应幻灯片
- [ ] `python main.py -ppt test.md` 能正常运行
- [ ] 无需 GPU、无需额外 API
- [ ] LLM 不可用时降级为规则分页（不崩溃）
